程序运行说明

一、运行环境
1.服务端
	操作系统：Ubuntu 64位（VMware虚拟机）
	Python版本：Python 3.12.3
2.客户端
	操作系统：Windows 11
	Python版本：Python 3.9

二、文件列表
1.udpserver.py : UDP服务端程序
2.udpclient.py : UDP客户端程序
3.readme.txt : 本运行说明文档
4.run_log.txt : 运行日志（程序自动生成）
5.udp_packet_capture.doc :说明文档

三、配置选项
1.服务端：
 	默认监听地址：0.0.0.0（所有网卡）
	模拟丢包率：30%（其中20%纯粹丢包，10%模拟损坏）
2.客户端：
	必须通过命令行指定服务端IP和端口
	固定发送窗口：5个数据包 × 80字节 = 400字节
	数据包总数：30个（每个80字节，总共2400字节）
	超时初始值：300ms，之后动态调整为最近RTT平均值的5倍（限制在0.1~1.0秒）

四、运行步骤
1. 启动服务端（在Ubuntu虚拟机中）：
	python3 udpserver.py

	服务端启动后会显示：
	[时间][SERVER]UDP服务端启动成功，监听0.0.0.0:8888
	[时间][SERVER]当前设定的模拟丢包率为：30.0%

2. 启动客户端（在Windows主机中）：
	打开命令提示符或PyCharm终端，进入代码所在目录，执行：
	python udpclient.py <服务器IP> <服务器端口>

	示例（虚拟机IP：192.168.13.128 端口8888）：
	python udpclient.py 192.168.13.128 8888

	客户端将自动进行三次握手、GBN数据传输，打印发送/确认/重传日志，最后输出统计信息。
